The published terms of service for the **Perfect Home Decor Poster** Android
app, served through GitHub Pages.

**Live page:** https://rizwan-dev.github.io/terms-of-service/

This URL is referenced from the app's Google Play listing. Google requires it to
resolve, so do not make this repository private or delete it — private
repositories lose GitHub Pages, which would break the store listing.
